# 卡皮九九大作戰

一款適合 PC 與 iPad 橫向遊玩的純 Web 九九乘法遊戲。

## 遊戲規則

- 80 秒內答對 10 題即過關。
- 點擊／觸控舉著正確答案的卡皮巴拉。
- 答錯會失去一顆橘子，最多五顆。
- 遊戲會依答對題數分成暖身、加速、衝刺三個速度階段。

## 本機預覽

這是無建置流程的靜態網站，可使用任何靜態伺服器，例如：

```sh
npx serve .
```

macOS 內建 Ruby 也可以直接預覽：

```sh
ruby -run -e httpd . -p 4173 -b 127.0.0.1
```

或使用其他靜態伺服器。不要用 `file://` 直接開啟，以免瀏覽器限制素材載入。

也可以直接部署至 GitHub Pages；入口檔案是根目錄的 `index.html`。

## 素材來源

場景與角色素材使用 Codex 內建 ImageGen，依核准的「C：軟陶玩具 3D」視覺方向製作。遊戲文字、題目與答案皆由 HTML 即時呈現。
